## Как повторить проверку

1. Создать пустую файловую базу. В Конфигураторе этой базы выбрать **Администрирование → Загрузить информационную базу** и указать [VoltMarket.dt](../dist/VoltMarket.dt). Проверки рассчитаны на отдельную копию с исходными демонстрационными остатками.
2. Запустить **1С:Предприятие** под пользователем **Администратор** с русским интерфейсом. В учебной поставке пароль пустой.
3. Выбрать **Файл → Открыть**, открыть `tests/ПроверкиБрони.epf` из этой папки и нажать **Запустить проверки**. Обработка выводит отдельную строку с результатом PASS или FAIL для каждого сценария. При FAIL в строке указана нарушенная проверка.

| Сценарий | Что проверяется | Фактический результат |
|---|---|---|
| ВМ-01 | При наличии одного свободного ноутбука бронь первого покупателя проводится. Второй получает отказ из-за нехватки. После отмены первой брони тот же документ второго покупателя успешно проводится. | Свободно 1 → 0 → 1 → 0. Зарезервированная единица принадлежит второму покупателю. |
| ВМ-02 | Продавец вручную снимает одну из двух единиц. Обработка моделирует истечение срока брони и вызывает тот же серверный метод, что и регламентное задание. | По этой брони создана одна автоматическая отмена на 1 шт. Всего отменено 2, выкуплено 0, в резерве 0. |

Два последовательных запуска на одной копии базы дали PASS по обоим сценариям. ВМ-01 выполняет заявки в одном сеансе и удаляет созданные тестом документы по ссылкам. ВМ-02 откатывает тестовую транзакцию вместе с изменениями, которые автоснятие могло внести в другие демонстрационные брони.
