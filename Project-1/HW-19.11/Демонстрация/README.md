# Запуск «ВольтМаркета»

| Компонент | Запуск |
|---|---|
| Redmine | [Создать свой стенд в GitHub Codespaces](https://codespaces.new/bluv4nul/ProjectsControl). Нужны аккаунт GitHub с доступом к Codespaces и интернет. Выберите ветку с заданием и конфигурацию **ВольтМаркет — защита в Redmine**, затем **Create codespace**. В открывшемся окне перейдите на вкладку **Ports** и откройте порт **3000** в браузере. Главная страница содержит ссылки **Задачи** и **Процессы**. |
| Конфигурация 1С | Скачайте [VoltMarket-1C.zip](./VoltMarket-1C.zip?raw=1), полностью распакуйте в новую папку и откройте **Start-Windows.cmd** или **Start-macOS.command**. Нужна установленная [платформа 1С 8.3.27](https://online.1c.ru/catalog/free/learning.php). В окне обработки доступна кнопка **Запустить проверки**. |
| СППР | [Официальная демонстрационная база 1С](https://demo.1c.ru/modeling). |

**Если порт 3000 не открывается или возвращает ошибку 502**, вернитесь в Codespaces на вкладку **Порты** (Ports). Нажмите **Добавить порт**, введите `3089` и нажмите **Enter**. Оставьте видимость **Private**. Нажмите значок глобуса в новой строке **3089**, чтобы открыть главную страницу Redmine.

[Памятка выступающему — Защита.pdf](../Защита.pdf)

## Локальный Redmine

При установленном Docker Desktop выполните в этой папке `docker compose up -d --wait`. [Главная страница](http://127.0.0.1:3089/) откроется после подготовки базы. Для остановки выполните `docker compose stop`.
