## Состав системы

| Требование задания | Реализация |
|---|---|
| Документы (≥ 2) | «Приход» (поступление товаров), «Расход» (продажа товаров), «Бронирование» (бронь товаров), «Отмена брони» |
| Регистр сведений | «Цены» — периодический, история цен продажи |
| Справочники | «Номенклатура» (с фотографиями), «Покупатели», «Поставщики», «Организации» |
| Подсистемы (≥ 2) | «Покупка», «Продажа», «Бронирование», «Аналитика», «Справочники» |
| Роли (3) | «Покупка», «Продажа», «Полные права» |
| Регистры накопления, отчёты | «ОстаткиТоваров», «Продажи», «ТоварыВРезерве»; отчёты «Остатки товаров» (на складе, в резерве, свободно), «Анализ продаж», «Брони покупателей» (СКД) |
| Бронирование (доработка) | Забронировали — товар ушёл из свободного остатка и не продаётся другому покупателю; продали по брони — товар списан со склада; отменили бронь — товар вернулся в свободный остаток |
| Дизайн | Фирменный стиль, начальная страница, иконки разделов, фото товаров |
| Дополнительно | Подбор товаров, ввод по артикулу, карточка товара в документах, подсказка о брони покупателя, дозаказ заканчивающихся товаров, китайский язык интерфейса, печать накладных и бланков брони |

## Как открыть базу

1. 1С:Предприятие → **Добавить** → **Создание новой информационной базы** → **без конфигурации**.
2. Открыть базу в **Конфигураторе** → **Администрирование → Загрузить информационную базу…** → `dist/VoltMarket.dt`.
3. Запустить базу в режиме **1С:Предприятие**.

Пользователи (пароли пустые):

| Пользователь | Роль | Язык |
|---|---|---|
| Администратор | Полные права | русский |
| Закупщик (Иванов Иван) | Покупка | русский |
| Продавец (Петрова Анна) | Продажа (в том числе брони) | русский |
| 中文界面用户（完全权限） | Полные права | китайский |

Вместо `.dt` можно загрузить `dist/VoltMarket.cf` (**Конфигурация → Загрузить конфигурацию из файла**, затем **F7**) — при первом запуске пустая база заполнится демо-данными сама.

## Работа с выгрузкой конфигурации

Загрузить конфигурацию из папки `config/`: Конфигуратор → **Конфигурация → Загрузить конфигурацию из файлов…** → **F7**.
После изменений в Конфигураторе выгрузка обновляется командой **Конфигурация → Выгрузить конфигурацию в файлы…** в ту же папку.
