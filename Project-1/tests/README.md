# Контрольный пример ВольтМаркета

`Автотесты.epf` — внешняя обработка с автоматизированным контрольным примером: 47 проверок учёта, бронирования, автоснятия броней, отчётов и прав. Результаты этих проверок приведены в протоколе испытаний (`reports/2.3_Протокол_тестирования.pdf`, приложение Б, таблица Б.4).

## Как запустить

1. Создать новую информационную базу и загрузить в неё `dist/VoltMarket.dt` (Конфигуратор → **Администрирование → Загрузить информационную базу…**). Проверки рассчитаны на демонстрационные данные этой базы.
2. Запустить базу в режиме 1С:Предприятие под пользователем **Администратор** (пароль пустой).
3. **Файл → Открыть…** → `tests/Автотесты.epf`. Если платформа предупредит о запуске внешней обработки, разрешить открытие.
4. Нажать **Запустить проверки**. Через несколько секунд в форме появится протокол: первая строка — сколько проверок пройдено, дальше по строке на каждую проверку (код, PASS/FAIL, фактический результат).

Без открытия формы проверки запускаются командой:

```
1cv8c.exe ENTERPRISE /F "<каталог базы>" /N"Администратор" /Execute "<путь>\Автотесты.epf" /C"ЗапуститьАвтотесты|<путь к файлу протокола>"
```

## Что делают проверки

| Коды | Что проверяется |
|---|---|
| Б01 – Б22 | Бронирование: свободный остаток, продажа и отмена по брони, просроченные брони, цена брони, повторяющиеся строки, ввод на основании закрытой брони, отмена брони задним числом |
| Р01 – Р16 | Учёт: поступления и продажи, контроль остатков (в том числе с учётом документов другими датами), отмена и уменьшение прихода, цены, фото, печать, отчёт о продажах, права ролей, уникальность артикула |
| П01 – П02 | Ввод по артикулу и названию, цена последней закупки |
| А01 – А07 | Автоснятие просроченных броней, отчёт «Остаток, забронировано, доступно», расписание задания, демо-данные |

Каждая проверка создаёт документы текущей датой и удаляет их после себя, поэтому демонстрационные данные не меняются. На время проверок регламентное задание автоснятия выключается и затем включается снова.

Исходный код проверок — модуль объекта обработки — лежит рядом в файле `Автотесты_модуль_объекта.bsl` для просмотра без 1С.
